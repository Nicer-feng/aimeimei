# iOS 客户端更新记录

## 0.1.0 - 2026-10-20

- 修正应用目标的设备范围，明确仅支持 iPhone，避免 XcodeGen 默认 iPad 配置触发 TestFlight 方向校验失败；打包时检查实际设备声明。
- 新增最低 iOS 17 的 SwiftUI 原生聊天客户端，复用现有账号和服务端会话。
- 接入图形验证码登录、钥匙串会话、历史管理、模型和思考档位、SSE、常用 Markdown、草稿及待核对恢复。
- 新增独立 GitHub macOS 构建和离线 UI 验收，输出模拟器应用、截图与明确标注的未签名真机 IPA。
- 新增手动 TestFlight 签名和上传工作流，兼容个人及团队 API Key，校验描述文件、证书和包名；现有未签名构建保持独立。
- 免费账号真机安装仍需本机有效签名；TestFlight 真正上传和测试分发需配置付费团队凭据并完成 Apple 处理。
