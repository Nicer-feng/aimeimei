# iOS 客户端更新记录

## 0.3.0 - 2026-10-22

- 新增相册选图和拍照提问，压缩为 JPEG，支持最多 5 张图片、上传进度、手动重试和移除。
- 新增图片草稿、历史缩略图与大图预览，按模型识图能力限制发送，图片单独发送也能核对服务器记录。
- 新增联网来源列表，展示引用标题、摘要和网页入口，仅允许 HTTP/HTTPS 来源链接。
- 沿用现有 OSS 直传和图片登记接口，上传与图片读取不向 OSS 发送平台 Cookie；不修改服务端、Web 或 Android。

## 0.2.0 - 2026-10-22

- 新增原生资料库，支持与 Web 同步收藏、取消收藏、阅读完整收藏快照和返回原消息；删除原会话后仍可查看保留的收藏。
- 新增会话、消息正文及收藏全文搜索，支持定位消息、防抖、过时响应隔离及退出后的数据清理。
- 新增提示词库预览与填入草稿，覆盖未发送内容需确认，不自动发送，不修改 Web 公共模板。
- 新增对应接口契约、状态隔离和模拟器 UI 回归；沿用独立 TestFlight 云端签名上传流程。

## 0.1.0 更新 - 2026-10-21

- 登录页支持密码与短信验证码切换，复用现有短信接口；支持验证码自动填充、重发倒计时和过期检查，换手机号作废旧验证码挑战。
- 短信配置不可用时保留密码登录，不自动注册账号、不自动重试发短信，不保存验证码。
- TestFlight 增加仅针对已合入 main 提交的 `ios/testflight/*` 发行标签入口；普通代码推送不触发上传，外部测试分发仍由后台操作。
- 声明仅使用系统 HTTPS 和钥匙串对应的出口合规选项。

## 0.1.0 - 2026-10-20

- 修正应用目标的设备范围，明确仅支持 iPhone，避免 XcodeGen 默认 iPad 配置触发 TestFlight 方向校验失败；打包时检查实际设备声明。
- 新增最低 iOS 17 的 SwiftUI 原生聊天客户端，复用现有账号和服务端会话。
- 接入图形验证码登录、钥匙串会话、历史管理、模型和思考档位、SSE、常用 Markdown、草稿及待核对恢复。
- 新增独立 GitHub macOS 构建和离线 UI 验收，输出模拟器应用、截图与明确标注的未签名真机 IPA。
- 新增手动 TestFlight 签名和上传工作流，兼容个人及团队 API Key，校验描述文件、证书和包名；现有未签名构建保持独立。
- 免费账号真机安装仍需本机有效签名；TestFlight 真正上传和测试分发需配置付费团队凭据并完成 Apple 处理。
