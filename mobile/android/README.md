# AI槑槑 Android 原生客户端

独立版本：0.6.6 回答阅读增强、分支追问与系统分享接收。Kotlin + Jetpack Compose，最低 Android 8.0（API 26）。
继续使用当前仓库和现有 https://feng.asia 服务器，复用现有后端和数据库，网页增加安卓工具定位与触控阅读适配。

## 当前交付边界

0.6.6：代码块使用本地词法着色、保留完整源码复制与横向滚动，宽表格独立横滑。普通段落继续支持选择引用及分支追问。支持流程图、思维导图、时序图、类图的 Mermaid 块可打开全屏图表与源码，缩放和复制；脚本随 APK 打包，禁网络、文件、导航和 JS 原生桥，绘制失败保留源码。尚不等同 Web 的全部 Markdown 插件或数学公式排版。

分支追问在回答下和文字选择菜单进入，复用现有账号与服务端开关，独立页面查看引用、历史、流式回答、停止和保存独立聊天。返回主聊天保留阅读位置，讨论结果带回已有草稿前可选择追加或替换。停止或结果未确认后只读取记录，不自动重发模型请求；分支未使用主聊天的后台生成服务，离开前应结束生成。

系统分享接收文字、链接与最多 5 张 JPG/PNG/WebP 图片（每张不超过 20MB），冷启动与已打开 App 使用同一接收流程。只读取 content URI，复制到私有缓存后预览、编辑、移除，确认后追加到当前账号的聊天草稿，点击发送才上传分享图片。未登录先登录，账号切换清除待分享内容，临时预览最多保留一小时；已确认加入的图片草稿按账号与会话私有保存。不会自动打开分享链接或自动调用模型。

0.6.5：聊天输入区可展开为全屏草稿编辑，自动沿用账号、会话隔离的本地草稿，支持字数、全文复制与确认清空。收起后回到聊天确认发送，不因展开或编辑自动调用模型。

原生手写识别支持相册、拍照、图片文件与本地预览，确认后才上传并识别；沿用 Web 的 10MB 和图片格式限制，TIFF 保留识别能力并提示本地不能预览。识别记录可查看、搜索、确认删除，结果可编辑后复制或确认追加/替换聊天草稿。上传与识别失败不自动重试 POST，已发起但结果未确认时可先刷新记录核对。OCR 与聊天图片私有缓存分开，切账号清理，OSS 上传不携带登录 Cookie。

个人用量页支持近 7/30 天和一年、每日 Token/调用/估算费用及模型详情；累计常用模型和聊天排行明确使用累计口径。仅读取当前账号已有统计，不冒充全站管理统计或原生停留时长。

登录支持密码与短信两种方式。短信入口读取 enabled/configured 配置；只有用户点击获取才发送，遵守冷却和服务器限流，不自动注册或绑定手机号。手机号、验证码、challenge 只留在内存，验证码错误不误报为现有会话失效。成功沿用现有加密 Cookie 会话，未开放时保留密码登录。

0.6.4：统一新版头像和抱电脑欢迎图；启动图标改为独立前景、背景的自适应图标，完整保留耳朵和脸型，适配不同启动器遮罩。

0.6.3：历史抽屉与更多工具进入原生聊天全文搜索，支持问题/回答筛选和关键词高亮，点击后定位原消息。搜索不限于最近 200 段聊天；需先部署新增的 GET /api/conversations/{id} 只读接口，沿用账号与归档检查。原会话已删除的收藏仍可在原生收藏页查看。

联网回答下展示来源入口，原生查看已保存的标题、链接、摘要，复制或交给外部浏览器打开。AI 档案在设置和工具页原生管理，支持搜索、四种类型、新增编辑、启停、排序、确认删除；当前账号私有，与 Web 同步。保存失败保留编辑内容，切账号清除页面数据，均不会自动发起模型请求。

0.6.2 修复更新弹窗：明确区分当前已安装版本和目标版本，下载完成后保留“待安装”，关闭弹窗或重启后可继续安装。不同版本使用独立 APK 文件与 URI；安装前重新核对 SHA-256、包名、实际版本和签名。检查更新采用无缓存请求并按版本排序，旧列表不能覆盖已发现的新版本；下载失败不会误报已经升级。

0.6.1：输入区、发送中和历史记录显示图片缩略图，点击可全屏缩放、双击还原、拖动和失败重试。整批图片先准备本地预览再上传；相机 EXIF 方向会修正。缓存按账号和附件 ID 隔离，重启可复用，退出账号清理；上传失败可重试，进程退出前未上传成功的文件仍需重选。图片缺少扩展名时按 MIME 补全，无效图片在上传前拦截。

模型列表标注图片、思考和原生联网能力，支持筛选图片模型。顶栏会话统计和回答下方 Token 明细使用服务端已保存用量；缺失用量不表示没有消耗。提示词库支持原生搜索、全文、新增编辑、确认删除和带入草稿，沿用 Web 的共享模板语义。已有草稿时确认追加或替换，不自动发送。

已接入：密码/图形验证码登录、Android Keystore 加密会话、新建/切换对话、发送和 SSE 流式接收、停止接收、模型切换、支持能力配置的模型三档思考、联网搜索开关、思考预览和展开、Markdown 历史阅读、复制、草稿和异常恢复、退出登录、云端构建和正式签名入口。

原生尚未完整接入：全部 Markdown 插件和数学公式排版。完整聊天和工具页复用当前 Web 功能；这些不代表已有原生 UI。图片和文档显示附件卡片；图片支持原生缩放预览，本次上传的文档可交给系统其他应用打开。历史文档接口仅返回元数据，不承诺下载原始办公文件。生成时正文以轻量可选中文本预览，保存确认后切换 Markdown；正文使用 Markwon，代码块和表格使用原生分块阅读，尚不等同 Web 的完整渲染能力。

只有用户点击发送才发起模型请求。模型和思考档位通过现有会话 PATCH 保存，与网页同步；不支持档位控制的模型不显示该菜单。联网请求复用服务器现有自动搜索策略，未勾选不等于禁止服务器已配置的自动联网。

### 消息可靠性与性能

- 使用 OkHttp 官方 SSE 组件处理 UTF-8 分片、多行、CRLF；不拼接裸 TCP 数据、不自行改后端协议。
- 回答独立缓冲，约 80ms 更新当前消息，轻量均速释放；`message_saved` 到达后立即结束队列，避免回答结束后还长时间逐字播放。历史 Markdown 不随 token 重解析。
- `finish_reason`、`[DONE]`、EOF 都不代表已入库。仅有效 `message_saved.message_id` 确认保存，保留 completed/interrupted/failed 区别。
- 点击停止才主动关闭 SSE；切后台不再停止生成。生成任务属于应用进程，不绑定 Activity/ViewModel 的销毁；前台服务在点击发送时启动，显示可点击返回/停止的通知，完成后自动退出。申请有时限的 CPU 唤醒锁，等待超过 15 分钟会取消并核对保存结果。
- 后台只收流和维护缓冲，不做 80ms 的界面刷新；返回前台直接追上已收到的进度，不重新发送、不追播全部旧字。原服务器只在完成/断连时保存回答，不能从数据库逐 token 读取；这里通过保留 SSE 获取实时进度。
- 强制停止应用、系统杀进程、断网、厂商极限省电仍可能断开。Android 15+ 对 dataSync 前台服务有每日后台额度；不能承诺永久保活。没有重构服务器为独立生成任务，进程断开后仍沿用已有部分保存逻辑。不承诺点击停止后上游立即停止计费。
- 回前台、重开会话或重启 App 只 GET 核对记录；恢复标记按账号、会话隔离，保存问题全文和发送前的消息 ID，不自动重发 POST。
- 未确认时保留预览并暂禁发送，有限重查后可手动刷新；“核对后继续”需要再次确认，避免将其它轮回答误当作本次成功。
- 草稿位于 App 私有本地存储，关闭系统备份，按账号和会话隔离。发送前先落恢复标记，确认失败可恢复输入；不保存密码。
- 用户上滚时停止跟随，点“回到底部”恢复；支持系统深浅色、软键盘、安全区和旋转保留 ViewModel。

### 真机验收顺序

1. 登录和正常冷启动默认显示新聊天；反复点击顶部加号不增加历史，首次发送后才建立会话。打开左侧历史，验证标题搜索、置顶、重命名和确认删除。
2. 切换模型；仅支持档位的模型显示快速/平衡/深度；测试联网开关。
3. 测试长回答、思考展开、上滚阅读、回到底部及复制，确认不会刷新历史列表。
4. 生成中按 Home 或切其它 App、锁屏，确认通知仍存在，返回后进度追上；生成完通知应撤掉。再测试主动停止、强杀和断网，恢复时应核对记录、不自动重复提问或把部分回答当作完成。
5. 输入长草稿，切会话/旋转/关闭并重开，确认恢复；切换账号不得串草稿。

云端单元测试用 MockWebServer，不登录真实账号、不调用付费模型。编译通过不替代以上真机联网验收。

## 正式版发布与更新

日常只发布长期签名正式包，用户不需要安装“AI槑槑·验证”。原有 `.dev` 验证包与正式版独立，可以卸载验证包。

1. 在独立 Android 分支实现功能；`codex/android-*` 分支与 main 运行云端内部测试、Lint 和编译，不要求本机 Java、SDK 或 Gradle。
2. 全部验收通过后同步 main，增加 `versionCode` 与 `versionName`，推送对应 `android/v版本号` 标签。
3. 正式流水线再次完成测试、Lint、签名构建，核对真实 APK 的包名、版本与签名，再生成 `update.json`。APK 和更新文件均上传完成后才公开 Release。
4. 核对签名与上一正式版一致，确认 APK 的 SHA-256、大小和公开更新文件一致。用户在正式版 **设置 → 关于 → 检查更新** 下载，由系统确认覆盖安装，保留当前登录与草稿。

正式包名固定 `asia.feng.aimeimei`。沿用已配置的 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD` 四项 Actions Secrets，不重新生成长期签名。签名私钥与密码不进入 Git、日志或安装包。初次配置的维护脚本为 `mobile/android/scripts/create-signing-key.sh`，仅在新项目尚未配置签名时使用。

更新器只接受同包名、更高 versionCode、预期大小、SHA-256 与当前证书一致的 APK。下载位于应用私有缓存，FileProvider 仅暴露更新子目录；首次安装需用户允许槑槑安装应用，不静默安装。原生生成期间禁止启动安装器。已公开版本不覆盖，不改变其他产品的 latest Release。

当前仓库公开，Release APK 和不含凭证的测试报告按仓库权限可见；正式包仍需现有账号登录。

## 可选配置

默认服务器是 `https://feng.asia/`，无需配置。仅在开发者明确需要其它 HTTPS 服务器时，在同一 Actions 页的 Variables 中新增 `ANDROID_API_BASE_URL`。要求只有 HTTPS origin，不能包含用户名、密码、路径、query 或 fragment。

## 构建环境

- 云端：Ubuntu 24.04、Temurin JDK 17、Gradle 8.13、Android SDK 36、Build Tools 36.0.0。
- 固定 AGP 8.13.0、Kotlin 2.2.20、Compose BOM 2026.01.00，避免动态依赖版本。
- 初期由 setup-gradle 安装固定版本 Gradle，使用 `gradle -p mobile/android ...`；当前不要求本机 Gradle 或 Wrapper。
- push 只匹配 `mobile/android/**` 和 Android workflow；普通网站改动不触发构建。也可手动运行。
- 默认 GITHUB_TOKEN 仅 contents:read，无服务器 SSH 权限，也无生产部署步骤。
- 测试和 Lint 先于 APK 交付；产物保留 7 天。缺少正式签名时 release 明确失败，不能降级为未签名 APK。

## 0.6.0 原生聊天附件与消息工具

- 输入区支持系统相册、相机和文件选择器；每轮最多 5 张图片、5 份材料。图片沿用 JPG/PNG/WebP、20MB 限制，材料沿用服务端格式与 50MB 限制，上传时显示进度，文档解析完成后才允许发送。图片发送前检查模型图片理解能力。

- 原生消息支持长按操作和选中文字后的“引用提问”，每轮最多 3 段引用，沿用网页格式和服务端功能开关；回答可收藏、取消收藏，原生收藏页支持搜索、查看全文与返回最近列表中的原消息。
- 系统分享菜单可分享消息文字。创建公开链接时确认回答/本轮/会话范围及 1小时/6小时/1天/7天有效期；已创建的链接可在当前弹窗撤销，不自动创建或发送分享。
- 朗读需用户主动选择音色、语速并开始，原生显示等待、播放、暂停和进度条。离开聊天或退到后台暂停，切账号/会话停止并释放播放器；尚未完成的语音下载不会在后台自动开始播放。
- 图片使用受保护接口下载并原生缩放预览。办公文档原件仅在本次应用缓存仍存在时可交给已安装的其他应用打开，历史文档仍可查看元数据及解析状态，不把“查看材料”描述为完整 Office 编辑。
- 本版本不改服务端或数据库，不调用真实账号和付费模型进行自动化测试。云端模拟接口验证不替代用户手机上的相机、文件提供器、音频焦点和覆盖安装验收。
