# OpenAI 月度额度

## 范围与默认值

- 后台管理 → OpenAI 代理 → OpenAI 月度额度，默认开启、每月 50 美元。
- 所有账号、网页、iOS、Android 共用额度，仅适用于 `api.openai.com` 官方模型，不按供应商显示名判断。
- 北京时间自然月，请求归属于开始请求的月份；跨月结束仍结算到原月份。次月自动使用新周期，不需要定时任务，不改变模型手动启用状态。
- 达额拦截新调用；已经发送的请求允许完成，因此可能略微超额，不是供应商账单硬上限。

## 计价口径

使用模型管理中的人民币输入/输出单价，按后台配置的人民币/美元汇率折算，默认 6.718。这个默认值沿用既有 OpenAI 模型配置的折算口径，不自动抓取汇率。调整汇率只影响后续请求，历史账本保持原价；关闭模型成本统计不免计入额度。

响应中的输入/输出 Token 是结算依据，缓存暂按普通输入价格保守计入。推理 Token 已在供应商输出 Token 中时不重复相加。外部 Key 消费、供应商额外工具费用、税费等不在本地 Token 估算内，不声称等同官方账单。

启用保护时没有单价的官方模型拒绝付费调用；关闭保护允许调用，并单独提示无单价、无法计费的请求数量。建议同时在 OpenAI 控制台给专用项目设置官方支出限制；平台不会代为修改官方账单设置。

## 账本与兼容

新增 `openai_budget_settings`、`openai_budget_events` 两张独立表，由现有 `init_db` 幂等初始化，不改既有消息格式。首次升级按当前月尚存的主聊天/写稿辅助/侧边讨论 Token 与可识别官方模型价格重建历史；不修改旧费用。已经删除的记录、未保存 usage 的旧摘要/媒体调用无法追溯，不补造供应商账单。后续账本不依赖聊天记录，删除消息、切换模型、重启均不会清空预算。

在统一 `open_model_request` 出口覆盖当前 Chat Completions/Responses 付费调用，包括主聊天、侧边讨论、写稿整理、上下文摘要、音视频增强。GET 模型目录和手动代理连通测试不计费、不被预算拦截；非 OpenAI 仍走原传输路径。未来新增其它 OpenAI 付费端点时需要扩充范围，不能假定自动覆盖。

请求前使用短 SQLite 写事务原子检查和预留，不在事务中请求网络。预留使用请求字节数和输出限制（未指定时 8192 Token）估算，不等同精确分词；接近上限时最多预留余额。完整 usage 按实际 Token 替换预留。明确 HTTP 4xx 拒绝释放预留，网络结果不明/断流缺 usage 按预留保守计入并提示，不自动重发付费请求。启动时仅将已退出进程的遗留预留转为不确定费用，不回收仍存活进程的任务。

响应封装只旁路提取 usage，返回原始字节，不缓冲等待完整音视频/聊天结果，不改变 prompt、思考参数、联网、流式播放或主对话滚动。SSE/JSON 审计缓冲有上限，不保存正文、Key、Authorization、订阅信息或用户资料。

## 接口与展示

- `GET /api/admin/openai-budget`：仅管理员，返回本月估算、预留、剩余、限额和不确定请求数量。
- `POST /api/admin/openai-budget`：仅管理员，接受 `enabled`、`limit_usd`、`cny_per_usd`。金额与汇率必须有限且为正，不能用 NaN/Infinity 绕过。没有清空账本接口，需要恢复时提高额度或关闭保护。
- 主聊天/侧边讨论预检查达额时返回友好 429，不为被拒绝的新发送保存空白消息。统一出口再次检查，防止并发与辅助调用绕过。
- 按需模型可用性检查在预算不足时直接返回原因，不请求 OpenAI；普通账号不获得平台费用明细。
- 后台仅进入该页、手动刷新或保存后查询，不新增定时轮询；80% 给管理员提示。

## 本地验证

`scripts/test_openai_budget.py` 使用临时库与回环 HTTP，覆盖权限、非法金额、全平台累计、并发预留、超额完成、跨月、故障估算、重启回收、历史重建和删除消息不重置。`scripts/test_openai_egress.py` 保留真实回环 TLS CONNECT 与主聊天/辅助调用兼容验证，`scripts/test_openai_egress_ui.js` 验证阈值保存、达额状态、按钮/数据对齐及深浅主题手机布局。均不调用真实模型，不产生付费测试请求。

发布需备份代码及一致性 SQLite 快照，等待主聊天/后台任务空闲后重启共享服务。新增表可保留用于回滚兼容，禁止自动恢复整个数据库覆盖上线后的新记录。
